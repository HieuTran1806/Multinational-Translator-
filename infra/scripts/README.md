# Infrastructure scripts

Chứa script hỗ trợ thiết lập, khởi động, kiểm tra hoặc vận hành môi trường dev/CI. Script cần tên mô tả rõ mục đích, xử lý lỗi và ghi rõ điều kiện tiên quyết.

Không đưa secret vào script; tránh thao tác phá hủy mặc định và cung cấp chế độ an toàn khi script có thể thay đổi dữ liệu.
