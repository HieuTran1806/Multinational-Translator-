# Cấu trúc dự án — nền tảng Giai đoạn 1

Nhánh hiện tại chỉ chứa tài liệu, cấu hình CI/CD và các tệp hỗ trợ kho mã. Phần triển khai ứng dụng được loại bỏ khỏi nhánh này để thống nhất hợp đồng trước khi xây dựng lại. Nhánh gốc `XuanHoai_UC01-03` vẫn giữ lịch sử triển khai trước.

Các miền triển khai dự kiến sau khi hợp đồng được thông qua:

- Ứng dụng di động User.
- API backend và lưu trữ dữ liệu.
- Ứng dụng web Admin.
- Luồng Seller/thanh toán/QR.
- Hạ tầng và môi trường phát triển cục bộ.
- Design token dùng chung nếu cần thiết cho việc triển khai giao diện.

Không tự dựng lại chi tiết thư mục hoặc lựa chọn framework dựa trên trí nhớ. Nhóm cần xác nhận công nghệ và ranh giới mô-đun trong giai đoạn lập kế hoạch triển khai.
