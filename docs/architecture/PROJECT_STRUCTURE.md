# Project structure — Phase 1 baseline

The current branch intentionally contains documentation, CI/CD configuration, and repository support files only. Application implementation was removed from this branch to establish a shared contract before rebuilding. The original branch `XuanHoai_UC01-03` retains the prior implementation history.

Expected implementation domains after contract sign-off:

- User mobile app.
- Backend API and persistence.
- Admin web app.
- Seller/payment/QR flows.
- Infrastructure and local development environment.
- Shared design tokens, where justified by the UI implementation.

Do not recreate directory details or framework choices from memory. The team should confirm technology choices and module boundaries during implementation planning.
