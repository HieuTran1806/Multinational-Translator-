# Mobile Offline

Chứa logic quản lý nội dung có thể sử dụng khi mất mạng: tải, lưu, liệt kê, cập nhật, xóa và trạng thái đồng bộ nếu được hỗ trợ.

Phạm vi liên quan UC09. Phân biệt dữ liệu đã lưu thành công với tác vụ đang tải/thất bại; tránh xóa dữ liệu không xác nhận. UI hiển thị progress/error theo trạng thái thật và test các tình huống mạng chập chờn.
