# Mobile i18n

Chứa resource bản dịch UI, cấu hình locale và tiện ích định dạng ngôn ngữ. Liên quan UC04 nhưng cần phân biệt ngôn ngữ giao diện với ngôn ngữ audio thuyết minh.

Dùng key nhất quán, có fallback được xác định rõ và không nhúng câu chữ lặp lại ở nhiều màn hình. Thay đổi ngôn ngữ cần giữ trải nghiệm nhất quán và kiểm tra text tiếng Việt dài.
