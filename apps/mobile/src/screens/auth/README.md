# Tourist authentication screens — UC01–UC03

Thư mục đích cho các screen/flow đăng ký, đăng nhập và đăng xuất của Tourist. Chứa UI cấp màn hình và kết nối với module auth/API; không chứa credential logic có thẩm quyền.

Hiện các screen có thể vẫn nằm trực tiếp trong `src/screens/`. Chỉ di chuyển sau khi cập nhật imports, navigation và test trong một thay đổi riêng.
