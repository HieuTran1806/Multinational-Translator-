# Mobile Navigation

Chứa route, navigator, guard và quy tắc chuyển màn hình cho Tourist Mobile.

Điều hướng phải khớp luồng Use Case, hỗ trợ back behavior hợp lý và không đưa các màn hình Admin Web vào app. Đăng xuất/đổi ngôn ngữ cần được đặt theo quyết định UX đã thống nhất; không tự tạo luồng ngoài phạm vi.
