# Mobile Components

Chứa component UI tái sử dụng trên nhiều màn hình: Button, Input, Card, feedback, loading, empty/error state và component theo design system.

Tuân thủ `docs/DESIGN_SYSTEM_TOKENS_AND_COMPONENTS.md` và `src/theme.ts`. Component nhận dữ liệu qua props, tránh chứa logic nghiệp vụ hoặc gọi API không cần thiết. Hỗ trợ accessibility và các trạng thái cần thiết.
