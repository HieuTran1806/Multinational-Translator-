# Mobile Types

Chứa type/interface/schema dùng chung cho dữ liệu API, model phía client và các trạng thái được chia sẻ giữa module.

Tránh tạo type trùng tên nhưng khác ý nghĩa; không dùng type frontend như cơ chế bảo mật. Khi API schema thay đổi, đồng bộ với `docs/architecture/api.md` và kiểm tra nơi sử dụng.
