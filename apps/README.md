# apps/

Chứa các ứng dụng client của sản phẩm. Hiện có Tourist Mobile tại `mobile/` và Admin/Super Admin Web tại `admin/`.

Giữ riêng entry point, dependencies, cấu hình và cách build của từng ứng dụng. Các quy tắc chung về Use Case, API, Design System và bảo mật nằm trong `docs/`; không đưa backend business logic vào đây.
