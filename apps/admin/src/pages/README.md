# Admin Pages

Chứa page/route-level components của Admin Dashboard. Page kết hợp components và feature modules, điều phối dữ liệu qua lớp API, và thể hiện loading/empty/error/success.

Ánh xạ page theo UC10–UC16 và giữ phân biệt giữa page thực sự có điều hướng với state/confirmation dialog. Không thêm màn hình ngoài phạm vi được duyệt.
