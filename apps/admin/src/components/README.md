# Admin Components

Chứa component UI tái sử dụng và tuân thủ Design System. Hiện có `ui.jsx` với Button, Spinner, Alert, Field, inputClass, Card, PoiStatusBadge và AudioBadge.

Trước khi tạo component mới, kiểm tra khả năng tái sử dụng/mở rộng component hiện có. Duy trì variants/states/accessibility; không để component dùng chung chứa logic nghiệp vụ riêng của một page.
