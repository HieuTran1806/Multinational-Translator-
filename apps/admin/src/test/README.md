# Admin Frontend Tests

Chứa test setup, helper và các test frontend dùng chung. Test component/feature cụ thể có thể đặt cạnh source nếu đó là quy ước đang dùng.

Ưu tiên kiểm tra hành vi người dùng, xử lý loading/error, API contract và quyền hiển thị. Không coi việc ẩn nút là kiểm thử phân quyền backend; các quyền phải có test phía server.
