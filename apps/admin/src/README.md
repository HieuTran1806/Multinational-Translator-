# Admin Web source

Chứa entry point, cấu hình frontend, API client, auth, components, features, pages và test.

- `api/`: giao tiếp backend.
- `auth/`: trạng thái phiên và bảo vệ truy cập phía client.
- `components/`: UI tái sử dụng.
- `features/`: chức năng nghiệp vụ Admin.
- `pages/`: màn hình cấp route.
- `test/`: kiểm thử frontend.

Giữ logic nghiệp vụ có thẩm quyền phía server; UI chỉ là lớp trải nghiệm.
