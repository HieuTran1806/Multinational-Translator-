# Audio Monitoring — UC11

Chứa UI/feature theo dõi tiến độ tạo audio, chi tiết job và trạng thái processing/completed/failed cùng hành động được Use Case cho phép.

Không suy diễn trạng thái hoàn tất từ polling timeout; chỉ hiển thị dữ liệu server xác nhận. Có thể phối hợp các module hiện có ở thư mục cha, chưa di chuyển file tự động.
