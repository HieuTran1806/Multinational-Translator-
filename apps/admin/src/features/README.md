# Admin Features

Chứa chức năng nghiệp vụ theo domain của Admin Web. Hiện có `AudioPanel.jsx`, `TranslationEditor.jsx`, `useJobPolling.js` và test liên quan.

Khi mở rộng, nhóm code theo chức năng đã được xác nhận trong UC10–UC16 (POI management, audio monitoring, user/admin management, roles/permissions, analytics, audit logs) nếu module đủ lớn. Không tạo bản sao của API/auth/components; không chuyển file hiện có nếu chưa cập nhật imports, tests và routing.
