# POI Management — UC10

Chứa feature quản lý POI phía Admin: danh sách, chi tiết, tạo/sửa, xác nhận xóa và publish theo Use Case. Tích hợp API, hiển thị loading/empty/error và xác nhận thao tác phá hủy.

Quyền CRUD/publish phải được backend kiểm tra. Không đưa component UI dùng chung vào đây nếu có thể đặt trong `src/components/`.
