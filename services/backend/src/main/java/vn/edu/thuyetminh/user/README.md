# User Management Domain — UC12

Thư mục đích cho domain quản lý tài khoản người dùng: model, service, API và persistence khi triển khai UC12 ở backend.

Không trộn nghiệp vụ Admin account (UC13) vào domain này. Xác thực và quyền truy cập dùng cơ chế chung đã thống nhất; backend phải validate mọi thao tác. Đây là README định hướng cấu trúc, không khẳng định UC12 đã được triển khai tại đây.
