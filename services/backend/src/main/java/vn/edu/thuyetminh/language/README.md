# Backend Language

Chứa nghiệp vụ và API dữ liệu liên quan ngôn ngữ, mã ngôn ngữ và lựa chọn ngôn ngữ được backend hỗ trợ. Liên quan UC04 và audio theo ngôn ngữ khi thuộc hợp đồng.

Dùng mã ngôn ngữ nhất quán; phân biệt locale giao diện với ngôn ngữ nội dung/audio. Validate giá trị ở backend và không hard-code mapping khác nhau ở từng controller.
