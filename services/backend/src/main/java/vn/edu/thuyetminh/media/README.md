# Backend Media

Chứa xử lý metadata và tích hợp media/file (ví dụ hình ảnh hoặc audio assets) theo kiến trúc hiện tại.

Validate loại/kích thước file, kiểm soát quyền truy cập và tránh tin vào filename/path từ người dùng. Không đưa file nhị phân hoặc media runtime sinh ra vào source nếu không phải asset demo được quản lý.
