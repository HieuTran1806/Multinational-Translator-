# UC02 — Khám phá bản đồ tương tác

```mermaid
flowchart TD
    S([Start]) --> A[Hoàn tất UC01 → Màn hình chính]
    A --> B[Tải ngầm PMTiles + danh sách POI]
    B --> C{Có mạng hoặc PMTiles đã cache?}
    C -- Không E1 --> D[Popup mất kết nối + blank grid]
    C -- Có --> E[Hiển thị bản đồ vector + POI]
    E --> F{Zoom-out có ≥ 3 POI gần nhau?}
    F -- Có --> G[Tự động gom Cluster + số lượng]
    F -- Không --> H[Hiển thị POI đơn lẻ]
    G --> I[Người dùng thao tác bản đồ / Locate Me]
    H --> I
    I --> J{Đã cấp quyền vị trí?}
    J -- Chưa --> K[Yêu cầu quyền Geolocation]
    K --> L{Người dùng đồng ý?}
    L -- Không E2 --> M[Đặt tâm bản đồ về Cổng vào]
    L -- Có --> N[Lấy tọa độ tĩnh]
    J -- Rồi --> N
    N --> O{Nhận được tọa độ?}
    O -- Không E3 --> P[Toast lỗi vị trí + tiếp tục polling]
    P --> N
    O -- Có --> Q[Chấm xanh + Accuracy Radius]
    M --> R{Chọn Cluster hay POI?}
    Q --> R
    R -- Cluster --> T[Bottom Sheet danh sách POI]
    T --> U[Chọn POI]
    U --> V[Di chuyển tâm bản đồ + mở chi tiết POI]
    R -- POI đơn --> V
    V --> W[Hiển thị Endonym + mô tả + ảnh + Audio]
    W --> X{Nhấn Play Audio?}
    X -- Có --> Y[Phát audio + highlight POI]
    X -- Không --> Z[Tiếp tục khám phá]
    Y --> Z
    Z --> AA{Đến kỳ polling vị trí?}
    AA -- Có A2 --> N
    AA -- Không --> I
    classDef alt fill:#fff3cd,stroke:#b8860b;
    classDef exc fill:#f8d7da,stroke:#b02a37;
    class G,T,U,V alt;
    class D,M,P exc;
```

**Chú giải**
- Luồng chính: tải dữ liệu → bản đồ → quyền/vị trí → chọn POI → chi tiết → audio.
- Luồng rẽ nhanh A1: Cluster → danh sách POI → chọn POI → chi tiết.
- Luồng rẽ nhanh A2: polling định kỳ để cập nhật vị trí.
- Ngoại lệ E1: offline và chưa có PMTiles cache → blank grid.
- Ngoại lệ E2: từ chối GPS → tâm bản đồ về Cổng vào.
- Ngoại lệ E3: không lấy được tọa độ → thông báo và tiếp tục polling ngầm.
