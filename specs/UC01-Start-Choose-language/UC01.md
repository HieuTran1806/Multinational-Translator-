# UC01 — Khởi động & Chọn ngôn ngữ

```mermaid
flowchart TD
    S([Start]) --> A[Người dùng truy cập URL]
    A --> B{Cookie / Local Storage có dữ liệu?}
    B -- Có, hợp lệ --> C[Hiển thị màn hình chào mừng + Bắt đầu hành trình]
    C --> D[Người dùng bấm Bắt đầu hành trình]
    D --> E[Unlock Web Audio Context]
    E --> H[Đi tới bước xác nhận / Màn hình chính]
    B -- Không có --> F[Hiển thị màn hình chào mừng + Bắt đầu hành trình]
    B -- Có nhưng hỏng E1 --> G[Xóa cache/storage lỗi]
    G --> F

    I --> J[Tải danh sách ngôn ngữ từ Server]
    J --> K{Tải thành công?}
    K -- Có --> L[Đọc ngôn ngữ trình duyệt / thiết bị]

    M --> N{Người dùng Thử lại?}
    N -- Có --> J
    N -- Không / xác nhận mặc định --> O[Cho phép Xác nhận với ngôn ngữ hardcode]

    Q -- Có --> T[Đặt giá trị gợi ý theo thiết bị]

    T --> U
    U --> V[2 lựa chọn độc lập: Display text + Audio]
    V --> W[Danh sách tải xong → Xác nhận Active]
    W --> X[Người dùng chọn ngôn ngữ]
    X --> Y[Người dùng nhấn Xác nhận]
    Y --> P
    P --> Z[Unlock Web Audio Context + điều hướng Màn hình chính]
```

**Chú giải**
- Luồng chính: truy cập → kiểm tra storage → tải/nhận diện ngôn ngữ → chọn → xác nhận → lưu → Màn hình chính.
- Luồng rẽ nhanh A1: người dùng cũ có cấu hình hợp lệ bỏ qua chọn ngôn ngữ.
- Ngoại lệ E1: storage hỏng → xóa dữ liệu → xử lý như người dùng mới.
- Ngoại lệ E2: lỗi tải API → thông báo + thử lại; nếu vẫn không thành công cho phép xác nhận với ngôn ngữ hardcode.
- Ngoại lệ E3: ngôn ngữ thiết bị không hỗ trợ → mặc định Tiếng Việt.
